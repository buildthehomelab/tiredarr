# Contributing to Tiredarr

Please don't. We're all very tired.

## If you must

1. Open an issue describing the nap you failed to take.
2. Wait.
3. That's the whole workflow.

## Code style

- Zero dependencies. Adding one means reading its docs, and no.
- Comments should be honest about how everyone is feeling.
- PRs are triaged on a first-in, never-out basis.

## Code of Conduct

Be kind. Everyone here is exhausted.
